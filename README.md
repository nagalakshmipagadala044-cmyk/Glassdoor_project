# Glassdoor Salary Prediction

Glassdoor Salary Prediction is a Machine Learning project that predicts job salaries using Glassdoor job listing data. The project applies data preprocessing, exploratory data analysis (EDA), NLP techniques, feature engineering, and multiple regression models to estimate salaries accurately.

## Features
- Data Cleaning & Missing Value Handling
- Exploratory Data Analysis (EDA)
- NLP Preprocessing on Job Descriptions
- Feature Engineering & Encoding
- Machine Learning Models:
  - Linear Regression
  - Decision Tree Regressor
  - Random Forest Regressor
- Hyperparameter Optimization using GridSearchCV
- Model Evaluation using MAE, MSE, RMSE, and R² Score

## Dataset
The dataset contains job-related information such as:
- Job Title
- Company Name
- Location
- Industry
- Company Rating
- Salary Estimates
- Job Description
